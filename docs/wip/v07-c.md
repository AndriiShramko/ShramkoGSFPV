## Contracts this lane assumes (lane B to confirm; the lead reconciles at merge)

Public roadmap — as in the plan, plus two optional fields the seed carries and the landing uses:
`GET /api/roadmap` -> `{"v":1,"items":[{"id","kind":"feature|idea|bug","status":"planned|in_progress|done",
"title":{"en",...},"text"?,"fromPilot":bool,"done"?:ISO,"release"?:sha,"group"?:string,"order"?:number}]}`.
`group` = the landing's group id (`radio controls drone crash camera scenes walls settings`); without it a
done item goes into a trailing "More" group, unless the snapshot already placed it (the seed's grouping
survives an API that does not echo `group`). `order` sorts within a column. nginx needs
`location = /api/roadmap` (GET only, no cookies) — whichever lane adds it.

Seed (written here, loaded once by B into an empty store): `apps/api/locales/roadmap-seed.json`
`{"v":1,"items":[{"id":"F-<slug>","kind":"feature","status":"done|in_progress|accepted","title":{en,es,pl,ru},"order":n,"group":"<id>"}]}`.

Admin ideas API: first assumed here (`ideas/status`, `ideas/thanks/draft`...), then switched to lane B's
real one (docs/wip/v07-b.md "Contracts for lane C", apps/api/ideas_admin.py on branch v07-b). All under
`/api/admin/`, session cookie, `X-CSRF` on POST, `{ok:false,reason}` on errors; every POST answers
`{ok, idea}` and the client redraws the card from it. `apps/fly/src/admin/ideas/api.ts` (IDEAS_ROUTES) is
the only place that knows these:

| Call | Body | Answer |
|---|---|---|
| `GET ideas` | | `{ok, ideas: record[], mail: {configured, from}, bot: {configured}, undoSeconds}` |
| `POST ideas/update` | `{id, status? / urgency? (null clears) / comment? / publicTitle?, visible?}` | `{ok, idea}` |
| `POST ideas/note` | `{text, contact, lang, urgency, kind: note}` | `{ok, idea}` |
| `POST ideas/reply` | `{id, text}` (queued behind the undo window; the server quotes the pilot) | `{ok, idea, mail}` |
| `POST ideas/done` | `{id, summary: {lang: text}}` (a DRAFT, nothing sent; null without an e-mail) | `{ok, idea, draft}` |
| `POST ideas/send-done` | `{id}` (the owner's Send under the draft) | `{ok, idea, mail}` |
| `POST ideas/mail/cancel`, `ideas/mail/send` | `{id: mailId}` | `{ok, idea, mail}`; cancel 409 once sending |
| `GET reports/<id>/diagnostics` | (exists today) | the stored JSON |

The record is lane B's (`created`, `lang`, `email`, `urgency` or null, `comments [{at,text,by}]`,
`public {title,text,visible}`, `done {at,summary}`, `notified`, `thread [mail]`); `parseIdea` maps it to
the board's `Idea`. A record with an unknown status or kind is not guessed into a column: the tab says
how many it could not show. The public roadmap carries no `group`: the prebuild snapshot gives a live item
its seed item's group by id; a new idea that is done goes under "More".

Seed path: lane B's server reads `apps/api/roadmap-seed.json` by default (`ROADMAP_SEED` overrides); this
lane writes `apps/api/locales/roadmap-seed.json` (B18). At merge: point B's default at `locales/`.

Title length: this lane allows 240 characters (`PUBLIC_TITLE_MAX`, test_roadmap_seed.py; the landing's
longest line today is 211, es). Lane B's `ideas.TITLE_MAX` is 140 and `clean_line` cuts silently
mid-word: 33 seed titles (7 of them English) would reach the live landing cut short while the static
snapshot shows them whole. At merge: B's TITLE_MAX = 240.

The relayed request of 2026-10-13 ("all user data in the chat too") is lane B's Telegram side; on this
side the card shows everything the pilot sent (the contact itself, language, page, scene, release,
diagnostics), not only whether a contact was left.

## Kanban rules

- Columns New / Accepted (the work queue) / In progress / Done / Rejected. Queue order: urgency, then
  `order`, then age; New and Rejected newest first; Done by done date, newest first.
- Move: drag a card onto a column; or focus a card's handle and press Left/Right; or the card's
  Column select (touch). A move to the same column sends nothing.
- Moving a pilot's idea with an e-mail to Done opens the thank-you dialog: the owner writes what was
  done in the pilot's language, `ideas/done` makes the draft, the whole e-mail is shown, and only Send
  (`ideas/send-done`) queues it. Reply by e-mail: a form on the card, sent only by its button, then
  Cancel on the card during the undo window.
- Roadmap visibility needs an English public title; missing languages are named on the card (the
  landing shows English there).
